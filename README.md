# Workbook Prompt Constructor — 2–4 класс

Конструктор промптов для генерации ESL workbook по материалу учебника.

## Источники
- Скриншоты учебника = содержание, лексика, грамматика, речевые функции, тексты и уровень.
- Фото №3 = визуальный мудборд: стиль, палитра, рисовка, персонажи, фон и декоративная система.
- Персонажи из учебника не используются.
- Отдельный unit focus не создаётся.

## Использование
1. Откройте `index.html`.
2. Выберите класс, учебный фокус (лексика / грамматика / чтение / говорение / mixed), число страниц и заданий.
3. При необходимости добавьте пожелание к мудборду.
4. Нажмите «Собрать промпт».
5. В нейросеть прикрепите скриншоты учебника и фото №3 с мудбордом.
6. Вставьте сформированный промпт.
7. «Другой вариант заданий» создаст новую методическую комбинацию.

Банк конструктора содержит 150 форматов заданий.


## Дополнительный контроль качества
В промпт добавлены отдельные требования против угадывания: нейросеть должна распределять правильные ответы без явного паттерна, делать правдоподобные дистракторы и проверять, что задания требуют реального мыслительного усилия, а не выбора первого очевидного варианта.
