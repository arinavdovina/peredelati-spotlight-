# Workbook Prompt Constructor — 2–4 класс (v4)

Конструктор промптов для генерации ESL workbook по постоянной системе из трёх изображений.

## Постоянная схема
- **Фото 1** — скриншот(ы) учебника
- **Фото 2** — скриншот(ы) учебника
- **Фото 3** — визуальный мудборд

## Жёсткое разделение ролей
### Фото 1 + Фото 2
Используются только для:
- темы;
- тематического контента;
- активной лексики;
- грамматики;
- речевых моделей;
- типов текстов/заданий;
- определения уровня сложности.

### Фото 3
Используется только для:
- персонажей;
- общей рисовки;
- палитры;
- композиции;
- декоративной системы;
- общего визуального настроения.

## Встроенные правила
- Персонажи не берутся из учебника.
- Дизайн учебника не копируется.
- Отдельный artificial unit focus не создаётся.
- Фото 1 и 2 не влияют на стиль.
- Фото 3 не влияет на содержание.
- В промпт встроена проверка против угадывания: правильные ответы не должны повторяться в одной позиции, а дистракторы должны быть правдоподобными.

## Использование
1. Откройте `index.html`.
2. Выберите класс, фокус, число страниц и режим расширения.
3. При необходимости добавьте короткое пожелание к мудборду.
4. Нажмите «Собрать промпт».
5. В нейросеть прикрепите фото 1, фото 2 и фото 3.
6. Вставьте сформированный промпт.
