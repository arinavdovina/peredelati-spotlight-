# Workbook Prompt Constructor — 2–4 класс

Статический сайт-конструктор промптов для создания ESL workbook по скриншотам учебника.

## Как работает
1. Откройте `index.html`.
2. Выберите класс, фокус, количество страниц, стиль и режим расширения материала.
3. Нажмите **«Собрать промпт»**.
4. В нейросети прикрепите скриншоты страниц учебника.
5. Вставьте получившийся промпт.
6. Кнопка **«Другой вариант заданий»** пересобирает методически совместимую структуру без изменения настроек.

## Файлы
- `index.html` — интерфейс.
- `styles.css` — оформление.
- `data.js` — банк форматов заданий и визуальных стилей.
- `script.js` — логика умного подбора, генерация структуры и промпта.

## Важная логика
Сайт сам не загружает и не анализирует учебник. Он проектирует промпт так, чтобы модель сначала проанализировала прикрепленные к сообщению скриншоты и только после этого создала тетрадь.

Банк содержит форматы по лексике, грамматике, чтению, говорению и смешанным заданиям. При генерации учитываются класс, фокус и методический этап страницы.
